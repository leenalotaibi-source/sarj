A voice agent that knows when to stop, when to keep going, and when to answer

The caller says «إيه», coughs, or the TV is on: the agent keeps talking. The caller says «لحظة» or «لا لا»: the agent stops. The caller says «اممم… بعد المغرب…»: the agent waits for them to finish. TurnSense does this from the sound and the words, on a laptop CPU, with no cloud service.

How it works: two speeds, one decision

Every 20 ms two channels arrive: the agent's clean voice and the caller's phone line with everything in it. A fast acoustic path decides in under a millisecond per frame. A slower words path (an offline speech recogniser, ~190 ms per request) can only make that decision sooner or more careful. Nothing waits for the network.

Remove the agent's echo

We correlate the agent and caller loudness to find the echo delay, then learn the echo strength per frequency band from a few seconds of agent speech and subtract it.

Telephone band 100–3400 Hz: wideband and phone audio look the same to every later step.
Learn this caller's voice

While the agent is silent, the caller answers. Their level (80th percentile of their own speech) becomes the reference for the rest of the call.

Interruptions come at full voice (0 to −4 dB). Backchannels, TV and side talk are 4–14 dB softer.
Count speech, with context

STOP after ~520 ms of speech in one run. Every dB softer than the caller asks for more; short words separated by pauses («لا … لا … لحظة») add up.

More careful right after the agent's phrase ends (backchannels live there), quicker after a question.
Words decide the hard cases

An offline Whisper tiny transcribes the run, and also scores each candidate command word on the same encoding (keyword spotting).

One isolated «توقف» and one isolated «نعم» sound identical. Only words separate them.
Answer at the right time

When the agent is silent: take the turn after ~700 ms of quiet, unless the caller is hesitating, ends on «و / يعني», asked to wait, or is still reading out the digits the agent asked for.

Same recogniser, one request per pause. Words can only add patience.

Latency beats accuracy

Whisper base is more accurate, but at 500–700 ms per request its words arrive too late to help (dev 92.2: no gain over acoustics alone). Tiny takes ~300 ms. Encoding a 10 s window instead of Whisper's usual 30 s cut it to ~190 ms while adding keyword spotting.

What we tried that did not work

A listener word that simply delays the stop: Arabic answers often start with one («إيه الأحد… زين، احجزه»), so real interruptions got late (real time 90.7). Now a listener word only asks the run to outlast a typical backchannel (800 ms). Automatic RESUME after a short stop talked over «خلاص خلاص…». Whisper with a prompt copied the prompt's stop words into its output.

Limits, honestly

  • Every development call is synthetic (TTS voices, generated noise) and labelled from its script. Real callers are messier: we built extra sets (xdev, holdout) to check we were not tuning to 24 voices, and our scores drop there (87 / 85).
  • The level rule assumes interruptions come at full voice. A tired or very polite caller who interrupts softly is stopped for later, or only by the words layer.
  • Before the caller has said anything (the agent's first sentence) there is no caller level yet, so a loud TV can still cause a stop.
  • Whisper tiny gets Arabic wrong often. We only trust it for short command and listener words, and never let it make the agent take the turn sooner, except when the caller has read out all the digits the agent asked for.
  • End of turn is measured on only two development calls (5 required pauses). Treat its score as a sanity check, not a measurement.
  • Real-time numbers include the recogniser's delay on a 4-core CPU. A slower laptop makes the words later; very late stop words are ignored, so the system then behaves like its acoustic part (Core 92.4), never worse.
  • In this page's live call, replies, the natural voice and live transcription come from Google Gemini when you add a key. The decisions are TurnSense's own. In the harness everything runs offline.

Run it yourself

pip install -r requirements.txt -r requirements-extra.txt     # kit + numpy, faster-whisper
python -c "from huggingface_hub import snapshot_download as d; d('Systran/faster-whisper-tiny', local_dir='models/faster-whisper-tiny')"
python -m ttbench.play --system my_system.py --calls all       # official real-time run, 24 calls (~10 min)
python tools/kit_eval.py                                       # same scorer, offline (~40 s)
TT_CFG="use_words=0" python tools/kit_eval.py                  # acoustics only
python -m pytest -q tests
